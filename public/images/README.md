# Imágenes de Unió

Sube aquí los logos y recursos gráficos. Se sirven desde la raíz `/images/...`.

Nombres sugeridos (para que pueda enchufarlos sin que me digas rutas):

| Archivo                | Uso                                             |
| ---------------------- | ----------------------------------------------- |
| `logo.png` / `logo.svg`| Logo de Unió en la cabecera (sustituye al emoji)|
| `logo-mono.svg`        | Versión monocroma para fondos claros/oscuros    |
| `icon-512.png`         | Icono de la app (PWA / marcador móvil), 512×512  |
| `og.png`               | Imagen para compartir en redes, 1200×630         |

Cuando los subas, dímelo y los conecto (cabecera, favicon y metadatos de compartir).

Formatos recomendados: **SVG** para logos (nítido a cualquier tamaño) y **PNG**
con transparencia para iconos.
